# Ranvier.Css

Typed CSS values and generated property bindings for F# on .NET and Fable,
with static asset extraction and reactive Ranvier.View integration.

Start with [installation and setup](guide/introduction.md), then explore:

- [Typed CSS values and styles](view/css.md).
- [Composable utilities and responsive styles](view/css-utilities.md).
- [Static extraction and CSS source imports](view/css-build.md).

The [repository](https://github.com/ranvier-org/Ranvier.Css) contains the
generator, compiler, importer, runnable examples and complete test workflows.
